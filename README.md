# 風機葉片上翼面壓模設計器 v1.0.1

給高中物理課用的靜態網頁。輸入葉片站位，預覽 NACA 2412 上翼面配對壓模，並下載可切片的 3D 列印 STL，或雷切用的雙層巴沙木／翼肋 SVG。

預設參數會把 450 mm 葉片拆成兩段。每一段的背板只包住**該段自己的扭角範圍**，再留下你設定的最薄背板（預設 5 mm，不得小於 3 mm）。第 2 段上模因此從舊版整支葉片共用的約 **67.5 mm** 降到約 **26.2 mm**。

## 怎麼打開

這是沒有建置步驟的靜態網站。GitHub Pages 請從倉庫根目錄提供 `index.html`。

本機預覽（ES module 需要網站伺服器，不能直接用檔案總管點開）：

```bash
python3 -m http.server 8765
```

然後打開 <http://127.0.0.1:8765/> 。three.js 與 OrbitControls 已放在 `vendor/`，沒有網路也能轉 3D 預覽。

## 怎麼用

1. 左側沿用原本的欄位名稱與預設值：木片厚度、模具間隙、兩側預留、背板厚度、扭轉軸、列印長度、站位表、葉根平面段、雙層短切、翼肋、M3 鎖耳、定位擋邊、鳩尾進階欄位。
2. 只有葉片長度超過列印機可用長度時才拆件。整段列印不會做凸舌或凹槽。
3. 「下載這段 STL」會同時存 `lower-concave-mold-NN.stl`（凹面下模）與 `upper-convex-mold-NN.stl`（凸面上模）。
4. 「下載雙層雷切 SVG」檔名是 `blade-two-layer-slits.svg`。翼肋模式的檔名是 `laser-upper-lower-ribs-NN.svg` 與 `laser-rib-base-slots.svg`。
5. 「儲存參數／載入參數」使用 `blade-mold-parameters.json`。沒寫進檔案的欄位會保留畫面上的值；模具做法（3D 列印或翼肋）不會寫進參數檔。
6. 3D 預覽畫的是即將匯出的同一份網格，可依段別與上下模開關。畫面上把上模往上移 28 mm 只是為了看清楚，**下載的 STL 沒有這段位移**。

### 鳩尾

凸舌、凹槽、2D 示意與 3D 預覽共用 `js/joint.js` 的同一條剖面。

- A 段尾端的凸舌與 A 是同一塊實體。舌根窄、外端寬。
- B 段起點是對應凹槽。入口窄、內部寬。
- 沿葉片長度方向滑合。高度方向沒有間隙，接縫兩面的背板在接縫處齊平。
- 單側間隙預設 0.4 mm（可調 0.1–3.0）。凹槽總寬 = 凸舌寬 + 兩倍單側間隙。標籤會寫成「每側 0.4 mm，凹槽總寬增加 0.8 mm」。
- 圓角在舌根向外擴進肩部，在舌尖把尖角修圓，不會把窄頸／寬頭的方向做反。
- 進階「手動調整」沒勾時，就算欄位裡留著自訂數字，幾何仍用建議值 0.4 mm／12 mm／4 mm／45°。
- 間隙大到凹槽會穿出模具外皮時，預覽會警告，並把寬度限制在外皮內側。

## 檢查封閉實體

需要 Node.js 18 以上，不必安裝套件：

```bash
node scripts/check-outputs.mjs
```

腳本用預設參數產生 4 個 STL（寫到 `tmp-output/`，不納入版本庫），並檢查：

- 沒有開放邊、沒有非流形邊、只有一個連通殼、體積為正
- 單側間隙 0.4 mm 時，網格上的凹槽比凸舌寬 **0.8 mm**
- 接縫兩側的背板高度一致
- 勾選 M3 鎖耳時，鎖耳與本體仍是同一個封閉殼
- 葉片短到不必拆件時，沒有凸舌

## 變更紀錄

### v1.0.1

- 列印機可用長度不再上限 250 mm，只要 80 mm 以上、並且大於鳩尾接合深度即可。預設仍是 250 mm。

### v1.0

- 版號從舊站的接合設計 v61 重新起算。
- 每段模具高度改依該段自己的扭角與曲面範圍計算，仍保留最薄背板 3 mm 的下限。
- 匯出的 STL 是單一封閉、可切片的實體。凸舌、凹槽、定位擋邊與 M3 鎖耳都跟本體接在一起。
- 鳩尾用一條剖面；間隙是精確的每側間隙，不再被弦向格子量化。
- 進階鳩尾關閉時固定使用建議值。
- 加入與 STL 相同網格的 3D 預覽。
- 補上木片厚度、模具間隙、列印長度必須大於接合深度等檢查。

## 先維持原樣、等老師決定的問題

這些行為與舊站相同，這次沒有改：

1. **翼肋切割線**只沿扭轉後的模面切一刀，沒有扣掉木片厚度加模具間隙。畫面仍提示要自行留出工作間隙。
2. **橫條承座做在上下兩片模**上，不只下模。啟用葉根接合段時，兩片模面會一起凹下。
3. **凹模 STL 的平背面朝 +z**、模面朝 −z。直接切片時模面會朝下，需要在切片軟體裡翻面。
4. **雷切葉片寬度用模具弦長**，不是上表面展開寬度。展開寬度只出現在「平片尺寸對照」。
5. **預設站位**從根部 0° 到 30 mm 處的 64.4°。這段扭角會讓第 1 段模具變得很高，零件列表也會出現超過 ±45° 的提醒。
6. **扭角正負號**沿用舊公式：正扭角讓後緣往 −z、前緣往 +z 轉。左右手方向沒有另外標註。

若之後要改其中任何一項，告訴我偏好即可。
